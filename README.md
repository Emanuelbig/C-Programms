# C-Programms 💻

Este repositorio contiene la recopilación de ejercicios y fundamentos de programación en **C** desarrollados durante mi paso por la **UTN**.

El objetivo de este espacio es documentar la resolución lógica de problemas y el entendimiento del código a bajo nivel. Tener bases sólidas en programación complementa mi perfil permitiéndome entender la viabilidad técnica y hablar el mismo idioma que los equipos de ingeniería.

## 🗂️ Estructura del Repositorio

Los ejercicios están organizados por carpetas

## 🛠️ Tecnologías

* **Lenguaje:** C
* **Compilador:** GCC (MinGW)

## 🚀 Cómo compilar y ejecutar

Para probar cualquiera de los ejercicios localmente:

1. Cloná este repositorio.
2. Navegá hasta la carpeta del ejercicio que quieras probar.
3. Compilá y ejecutá usando tu entorno preferido (VS Code con C/C++ Runner o Code Runner o si no por terminal).
